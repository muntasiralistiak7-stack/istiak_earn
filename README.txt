ISTIAK EARN — Demo website
==========================
Open index.html in a browser to preview.

Included:
- Responsive Bengali dashboard with purple and black theme
- Home, tasks, team, withdrawal, and account screens
- Clickable demo tasks and copy referral code
- Withdrawal request UI (does NOT send payments)
- Reset demo data

Important:
This is a front-end prototype only. It has no server, authentication, database, referral verification, task verification, or payment integration. The displayed balance is demo data, not withdrawable money. Before public launch, add a secure backend, admin panel, privacy/terms pages, anti-fraud checks, and legitimate payment-provider integration. Never collect passwords or payment PINs in this prototype.
